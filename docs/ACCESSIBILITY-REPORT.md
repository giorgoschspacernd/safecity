# Αναφορά προσβασιμότητας – μεταφορά από Google Sites

**Στόχος:** WCAG 2.1 επίπεδο AA (έλεγχος με WAVE / AChecker)
**Ημερομηνία:** 28/09/2026

## 1. Προβλήματα του αρχικού site (Google Sites) και πώς λύθηκαν

## 2. Τι προστέθηκε

- **Skip link** «Μετάβαση στο κύριο περιεχόμενο» (2.4.1).
- **Landmarks**: `header`, `nav` (με `aria-label`), `main`, `footer`. Σωστή σήμανση της τρέχουσας σελίδας με `aria-current="page"`.
- **Ορατό focus** (3px περίγραμμα) σε όλα τα στοιχεία (2.4.7). Στο κινητό, το κουμπί «Μενού» έχει `aria-expanded` και κλείνει με Esc.
- **`title` στα iframes** (YouTube, Google Forms) και εναλλακτικός σύνδεσμος για άνοιγμα της φόρμας σε ξεχωριστή σελίδα (4.1.2).
- **Responsive**: χωρίς οριζόντιο scroll στα 320px, δηλαδή σε zoom 400% (1.4.10). Αντέχει στις ρυθμίσεις απόστασης κειμένου (1.4.12).
- **Δήλωση προσβασιμότητας** (`/accessibility/`), με σύνδεσμο στο footer.
- `prefers-reduced-motion`, `forced-colors` (High Contrast των Windows), στυλ εκτύπωσης.

## 3. Αποτελέσματα αυτόματων ελέγχων (7 σελίδες × desktop 1280px + κινητό 375px)

| Εργαλείο | Αποτέλεσμα |
|---|---|
| axe-core 4.13 (wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa, best-practice) | **0 violations** |
| HTML_CodeSniffer 2.5 (WCAG2AA), ο κινητήρας κανόνων τύπου AChecker/pa11y | **0 errors** |
| W3C Nu HTML Checker (HTML + CSS) | **0 errors, 0 warnings** |
| Reflow 320px / Text spacing | Χωρίς οριζόντιο scroll |

Σημεία που θέλουν έλεγχο από άνθρωπο (warnings, όχι errors):

- **Τίτλος πάνω σε φωτογραφία (banner):** τα εργαλεία δεν μπορούν να μετρήσουν αντίθεση πάνω σε εικόνα. Ο λευκός τίτλος έχει σκούρο φίλτρο 45% και σκούρο χρώμα φόντου (`#1C3440`, αντίθεση 12:1), οπότε είναι ευανάγνωστος.
- **Κρυφό κείμενο «(ανοίγει σε νέα καρτέλα)»:** είναι σκόπιμα αόρατο, διαβάζεται μόνο από αναγνώστη οθόνης.

## 4. Εκκρεμότητες εκτός του δικού μας κώδικα

- **Βίντεο YouTube:** αν έχει ομιλία, χρειάζεται **υπότιτλους** (1.2.2 A), τους οποίους προσθέτει ο κάτοχος του καναλιού (CERTH HIT) στο YouTube Studio. Το WAVE θα το δείξει ως *Alert*.
- **Google Forms:** η φόρμα φιλοξενείται από τη Google και η προσβασιμότητά της δεν ελέγχεται από εμάς. Αν χρειαστεί πλήρης έλεγχος, μπορεί να αντικατασταθεί από HTML φόρμα με Azure Function.
- Οι εικόνες των αφισών έχουν την ανάλυση του πρωτοτύπου (537×727). Αν υπάρχουν τα αρχικά PDF, καλό είναι να μπουν και σύνδεσμοι λήψης (προσβάσιμα PDF).
